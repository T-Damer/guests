# Порядок реализации v0.2

[Карта](DESIGN.md). Документ задаёт зависимости, не обещает даты и не утверждает готовность ненаписанных систем.

## Что зафиксировано в этой документационной задаче

- [x] Описан путь от живого меню до возвращения на этаж.
- [x] Разделены мир, loop, системы, первое дело, каталог, UI, графика, звук.
- [x] Уточнены авторитетная архитектура, границы сохранения и загрузки.
- [x] Приведены реальные источники ассетов и политика приёмки.
- [x] Отделены существующий bootstrap и целевой вертикальный срез.

Код, сцены и runtime-баланс этой задачей не меняются. Проверки документационного пакета фиксируются в CI, а не отмечаются здесь заранее.

## M0 — сохранить рабочую основу

- [ ] Повторить базовые проверки на исходном рабочем SHA.
- [ ] Устранить audio-lifecycle предупреждения отдельным воспроизводимым исправлением.
- [ ] Сохранить существующий наряд как регрессионный сценарий.

Не повод останавливать всё производство до идеальной полировки: сетевые задачи могут готовиться в непересекающихся путях, но предупреждения остаются видимыми.

## M1 — два человека в существующей смене

- [ ] Авторитетные тела и общая камера каждого участника.
- [ ] Команды взаимодействия с проверкой range/occlusion/owner.
- [ ] Атомарный подбор, повтор запросов, возврат критических предметов.
- [ ] Общие состояние №027, радио, питание и завершение.
- [ ] Реальный solo/duo-прогон старого наряда.
- [ ] Решение по внешнему подключению и тест двух разных сетей.

## M2 — домашняя рамка

- [ ] Меню с малой 3D-сценой и статичным fallback.
- [ ] Приватный жилой этаж с личными комнатами и снабжением.
- [ ] Слоты кампании и сохранение безопасной границы.
- [ ] Вход друга в комнату без дублирования общего имущества.
- [ ] Выбор дела, комплект, ready-check в лифте.

Принимается без финальной мебели: главное — управляемый путь и совместное состояние. Не вводить свободное строительство квартир.

## M3 — переход и первое дело v0.2

- [ ] Общая машина загрузки и явные ошибки.
- [ ] Короткий внешний подход и вход через затемнение.
- [ ] Читаемый планшет и карточка №027.
- [ ] Отдельно внедрённый учебный профиль и тест цепи.
- [ ] Штатный путь, ошибка с восстановлением, уведомление об уходе.
- [ ] Общая сдача, debrief и возвращение в хаб.

Принимается весь цикл целиком. Не обязательно движение существа на первом интеграционном коммите, но завершённый угрожающий вариант требует M4.

## M4 — контригра и художественная версия

- [ ] Ограниченный поиск по наблюдениям.
- [ ] Одно настоящее укрытие и ясное правило проверки.
- [ ] Мягкий захват/освобождение, решаемые соло и вдвоём.
- [ ] Одна законченная модель №027 с читаемой деформацией.
- [ ] Согласованные поверхности и внешний кадр мегахрущёвки.
- [ ] Звуковой набор, субтитры, настройки комфорта.
- [ ] Графический и человеческий прогон финальных Linux/macOS-пакетов.

Называем это первым полноценным вертикальным срезом, если solo/duo действительно прошли его. Четыре игрока — отдельная проверка перед публичным обещанием 1–4 в текущей сборке.

## M5 — доказанная повторяемость

- [ ] Три независимые человеческие сессии и разбор решений.
- [ ] Два авторских варианта знакомого дела без изменения базовых правил.
- [ ] Второй жилец №014 и один конфликт условий с №027.
- [ ] Устойчивый прогресс в хабе, не экономика гринда.

Остальные досье — backlog. Внедрять их по одному, когда существующий цикл даёт осмысленные решения. Большой каталог не является самоцелью.

## Открытые решения владельца

Способ распространения и сервис удобного интернет-приглашения; целевое железо для performance budget; общая лицензия собственного кода; финальные имена ведомства и героев; глубина финальной сюжетной развилки. Остальная архитектура фиксирована в [ARCHITECTURE](ARCHITECTURE.md) и не требует повторного обсуждения перед каждым коммитом.
