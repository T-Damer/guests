Дополнительно закрепить архитектуру, источники free/openly licensed assets и производство в основном силами ИИ. Стилевой ориентир — мегахрущёвки и бетонная среда VHOLUME без копирования её контента.

`AGENTS.md`, `docs/`, `tools/design.py`, `.github/workflows/design.yml`. Runtime GDScript, сцены, шейдеры, экспортные настройки, текущий manifest и игровое tuning не меняются. Новый tuning JSON принадлежит только docs и помечен как proposal.

Индекс; девять профильных дизайн-документов; расширенные architecture/assets/workflow; roadmap; первичные источники; JSON стартовых гипотез; уточнённый узкий контракт 002. Одной командой собираются ZIP с раздельными Markdown и единый связанный Markdown для чтения.

## Проверки

`python3 tools/design.py check` проверяет наличие разделов, локальные ссылки, ограничение AGENTS, статус tuning и согласованность предлагаемого solo-окна. `package` создаёт комплект с SHA. Эти проверки не являются тестом будущего игрового цикла. Отдельно проверить отсутствие изменений в runtime-путях по сравнению с базой.

## Review

Проверить, что первое дело решаемо соло и вдвоём; радио не магический щит; поддержка имеет понятные правила; хаб безопасен; остальные существа не попали в обязательный scope; сетевое приглашение не объявлено готовым; новые источники не названы уже импортированными. Окончательная оценка рабочего баланса требует будущего игрового теста.
