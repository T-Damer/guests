ГОСТИ / GUESTS — macOS Universal 2, прототип 0.1

Распакуйте архив и перенесите GUESTS.app в «Программы», затем откройте его.
Один .app содержит версии для Intel x86_64 и Apple Silicon arm64.
Godot, Python и компилятор для запуска не нужны.

ЭТО ТЕСТОВАЯ СБОРКА: ad-hoc-подпись, без Apple Developer ID и notarization.
Сборка выполнена на Linux. Нативный запуск проверяется отдельной задачей
macos-smoke в GitHub Actions; смотрите результат для SHA из BUILD_INFO.json.

При блокировке непроверенного разработчика:
Сначала попробуйте открыть GUESTS.app. Затем в «Системные настройки» ->
«Конфиденциальность и безопасность» выберите «Всё равно открыть» для этой игры.
Название раздела может отличаться в старой macOS. Подтверждайте только если
доверяете источнику сборки. Не отключайте Gatekeeper для всей системы.
Если macOS сообщает именно об обнаруженном вредоносном ПО — не обходите это.
Инструкция Apple: https://support.apple.com/en-us/102445

Управление:
WASD — движение, мышь — взгляд, E — действие, R — обещать вернуться,
F8 — ретро-эффекты, F9 — звук, Esc — отпустить мышь, F6 — новая смена.
Для F-клавиш на некоторых клавиатурах Mac нужно удерживать Fn.

Это одиночный прототип. Подопечная меняет состояние и вытягивается,
но преследование, укрытия и полноценный кооператив пока не реализованы.
Текущий звук — заготовка; известное предупреждение об аудиообъектах при выходе.
Версия исходников и уровень проверки указаны в BUILD_INFO.json.
SHA256SUMS содержит контрольные суммы отдельных файлов пакета.
