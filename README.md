# ГОСТИ / GUESTS

Прототип хоррора от первого лица: ночная бригада обслуживает жилой корпус с изменившимися подопечными. Нужно не убивать их, а закончить смену, сохранив контакт.

**Это старт проекта, не готовая кооперативная игра.** Сейчас есть одиночный эпизод и отдельно проверяемый авторитетный сетевой контур. Синхронизация персонажей и настоящий совместный игровой прогон — следующий этап.

## Запуск рабочей ветки

Нужны Git и Python 3.11+. Движок загружается с официального релиза и проверяется по SHA-512; ассеты — по закреплённым SHA-256.

```bash
git clone --branch feature/bootstrap https://github.com/T-Damer/guests.git
cd guests
python3 tools/dev.py setup
python3 tools/dev.py check
python3 tools/dev.py run
```

На Windows команда Python может называться `python`. Для уже установленного редактора задайте `GODOT_BIN` — полный путь к Godot **4.7.2 stable**. На macOS это путь внутри `Godot.app/Contents/MacOS/Godot`. После `prepare` проект можно открыть обычным Godot Editor и редактировать сцены и Resources вручную.

`setup` и первое `prepare` требуют сети. Игра и последующие запуски используют локальные файлы. В офлайн-среде ИИ можно получить проверенный Linux-инструментарий через workflow `Toolchain cache`; для локального архива мебели предусмотрен `ASSET_ARCHIVE`.

## Что уже заложено

Один этаж: безопасный пост, тёмный коридор, комната подопечной №027. На посту лежат лампа и предохранитель. Восстановите питание у щитка, принесите лампу, представьтесь подопечной, включите радио и вернитесь к журналу смены.

Радио поддерживает контакт в отсутствие сотрудника. Без него после предупреждения подопечная начинает вытягиваться. Обещание вернуться даёт ограниченное окно работы. Сейчас это проверяемые состояния и визуальная деформация, **не завершённая система преследования**.

Используются шесть готовых моделей Kenney Furniture Kit (CC0). Стены, персонаж и звук — собственные явно обозначенные прототипные заготовки. Никакие модели, записи или сюжетные материалы Resident Evil, SCP или К.О.Н.Т.У.Р. не скопированы.

Управление: **WASD** — движение, мышь — взгляд, **E** — действие, **R** — обещать вернуться при наведении на подопечную, **F8** — убрать ретро-эффекты, **F9** — выключить звук, **Esc** — освободить мышь, **F6** — новая смена. Инвентарь отображается постоянно, без отдельного меню.

## Команды для человека и агента

| Команда | Результат |
|---|---|
| `python3 tools/dev.py setup` | Зафиксированный Godot с проверкой официальной контрольной суммы |
| `python3 tools/dev.py prepare` | Проверенные ассеты и импорт проекта |
| `python3 tools/dev.py check` | Импорт, структура, правила, взаимодействия в сцене, два ENet-процесса, headless-запуск |
| `python3 tools/dev.py capture` | Три графические фикстуры (включая эффекты off) и журнал в `artifacts/` |
| `python3 tools/dev.py export` | Linux debug-клиент и запуск экспортированной игры |
| `python3 tools/dev.py export --release` | Linux release-клиент; не публикация и не продвижение ветки |

Для захвата на Linux без экрана: `xvfb-run -a python3 tools/dev.py capture`. Для звука нужна отдельная проверка прослушиванием. Захваты не являются замером FPS.

CI сохраняет SHA, исходники, журналы, скриншоты и Linux-сборку как артефакт `guests-evidence-<sha>`. Проверяйте **фактический результат workflow для нужного SHA**, а не наличие workflow-файла. Ветка `stable` не создаётся и не обновляется автоматически; в будущем её CI будет собирать release-артефакт.

Для PS1-подобного прототипа выбран Compatibility renderer с динамическими локальными источниками и тенями. Динамическое глобальное освещение пока не требуется. Это не браузерный проект: будущая сеть использует ENet. Forward+ рассматривается только после измеряемой необходимости, а не для усложнения стека.

## Пока отсутствует

Полноценный игровой кооп и его UI, client prediction/interpolation, лобби/relay, сохранения, преследование с поиском по последним наблюдениям, захват и спасение товарища, настоящие укрытия, финальный персонаж и звуковая режиссура. Нет крафта, боёв, генератора этажей, живого LLM-диалога и собственного ECS.

Ограничения платформенной проверки: CI на Linux; Windows/macOS и обычный игровой ПК требуют отдельного прогона. Лицензия собственного кода проекта владельцем пока не выбрана; лицензии чужих материалов перечислены в [NOTICE.md](NOTICE.md).
